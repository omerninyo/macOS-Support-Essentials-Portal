
# שיעור 06: מערכת הקבצים (APFS)
**מעבדה מעשית (תרגול לתלמיד)**

## מעבדה: ניהול APFS, פתרון תקלות ב-Spotlight וחקר Clones

### מטרת המעבדה:
ללמד את הסטודנטים לעבוד עם הכלים המובנים של macOS (ממשק משתמש וטרמינל מתקדם) כדי לנתח חלוקת מקום דינמית, לחקור Firmlinks, להתמודד עם בעיות מקום פנוי שגוי באמצעות Spotlight, לאמת את הגדרות האבטחה (SSV) עבור כלים ארגוניים, ולהבין את הקסם של מנגנון ה-Clones.

### תרחיש:
משתמשת פונה אליכם ומתלוננת: "מחקתי המון קבצים אבל המחשב עדיין אומר שאין לי מקום בגלל System Data עצום, ובנוסף, המחשב בקושי מתפקד כשמעתיקים קבצים גדולים!". באותו הזמן, איש ה-IT מבקש מכם לאשר שהמערכת מאובטחת לפני פריסת אנטי-וירוס ארגוני.

---

### שלב 1: הכנת כונן העבודה האישי שלכם (USB) בממשק הגרפי
בקבלתכם קורס קיבלתם כונן USB. נשתמש בו כסביבת הניסויים שלנו כדי לא לסכן את כונן המערכת האמיתי ולמנוע בעיות של `fsck_apfs` (Failure to unmount) העלולות לצוץ בבדיקת כונן חי.

1. חברו את כונן ה-USB שלכם ל-Mac.
2. פתחו את תוכנת ה-**Disk Utility**.
3. בשורת התפריטים העליונה, לחצו על **View** ובחרו **Show All Devices**.
4. אתרו בצד שמאל את הכונן הפיזי החיצוני שלכם.
5. לחצו על כפתור ה-**Erase**.
6. בחרו שם (למשל `StudentDrive`), הגדירו את הפורמט ל-**APFS**, ואת הסכמה ל-**GUID Partition Map**. לחצו על Erase.
7. כעת יש לכם Container ו-Volume. לחצו על ה-Container הראשי וראו כיצד הוא מציג את חלוקת המקום.

### שלב 2: יצירה וניהול Volume דינמי ב-APFS
1. בחרו בצד שמאל את כרך ה-`StudentDrive` החדש שלכם ב-Disk Utility.
2. לחצו על סמל ה-**(+) Volume** בשורת הכלים העליונה.
3. קראו לו בשם **SharedPool**. תוכלו גם ללחוץ על Options ולהגדיר Quota למקרי קצה, אך לצורך התרגיל פשוט לחצו **Add**.
4. שימו לב כמה מהר הוא נוצר! הקיליקו עליו וראו שהמקום הפנוי שלו זהה לחלוטין לזה של ה-`StudentDrive`. שניהם חולקים את אותו המאגר (Dynamic Space Sharing).

### שלב 3: חקר מנגנון ההפרדה (Firmlinks) ואבטחת SSV ל-IT
נחזור למערכת המקומית כדי לענות לאיש ה-IT ולהבין מדוע לא ניתן למחוק "קבצי מערכת":

1. נסו ליצור קובץ ריק בכונן המערכת בטרמינל (כדי לראות את חסימת ה-SSV):
   ```bash
   sudo touch /System/test.txt
   ```
   *(שגיאת `Read-only file system` מוכיחה שה-SSV חתום וסגור)*

2. הריצו את הפקודה שמאשרת את חתימת האבטחה הקריפטוגרפית (טוב להרגעת מנהלי אבטחה לפני התקנת AV):
   ```bash
   csrutil authenticated-root status
   ```
   *(הסטטוס `enabled` אומר שאין צורך לסרוק את מחיצת המערכת נגד וירוסים)*

3. בדקו היכן ממוקמים ה-Firmlinks שמגשרים מעל ההגבלות הללו:
   ```bash
   cat /usr/share/firmlinks
   ```
   *(שימו לב לנתיב `/Applications` המאחד בין קבצי קריאה-בלבד לנתוני המשתמש)*

### שלב 4: טיפול באשליות מקום (בנייה מחדש של Spotlight)
הפתרון המומלץ לבעיית ה-"System Data" המזויף של המשתמשת:

1. פתחו **System Settings** > **Siri & Spotlight** > **Spotlight Privacy...**.
2. גררו את ה-Macintosh HD פנימה ולחצו **Done**. פעולה זו מוחקת את מסד הנתונים הישן.
3. היכנסו שוב והסירו את הכונן. 
4. פתחו **Activity Monitor**, טאב ה-CPU, וחפשו `md`. תהליכי `mds_stores` או `photoanalysisd` יזנקו. המחשב בונה את האינדקס מחדש!
*(הערה: אם התהליך לוקח ימים – Runaway Indexing – יש להניח לו לסיים אלא אם מבודדים קובץ ספציפי בעייתי).*

### שלב 5: חקר APFS Clones (אפקט הוואו על ה-USB)
נפתור למשתמשת את בעיית הביצועים בהעתקת קבצים גדולים על ידי הדגמת ה-Clones:

1. העתיקו (Copy & Paste) קובץ וידאו כבד אל ה-**StudentDrive**. פעולה זו תיקח זמן כי מבוצעת כתיבה פיזית לכונן החיצוני.
2. ב-Finder בתוך `StudentDrive`, סמנו את הקובץ והקישו `Cmd + D` (שכפול).
3. השכפול קורה **בשבריר שנייה**! ה-Finder השתמש אוטומטית במנגנון ה-Clone.
4. **הוכחת Zero-storage:** בטרמינל, הריצו:
   ```bash
   du -h /Volumes/StudentDrive/*
   ```
   *הקובץ המקורי ישקול את משקלו המלא, אך המשוכפל ישקול **0B**!*
