## תרגיל 1 — התקנה מחבילת PKG ובחינת חתימה

> **מה לומדים:** PKG = מתקין מערכתי. תמיד ידרוש Admin כי הוא כותב לנתיבים מוגנים.

1. פתחו את קובץ ה-`.pkg` שקיבלתם מהמדריך (לחיצה כפולה)
2. אשף ההתקנה ייפתח. בפינה הימנית עליונה — מנעול 🔒
3. לחצו על המנעול → בדקו שרשום **"Developer ID Installer"** (מפתח מאושר)
4. בשורת התפריטים: **File → Show Files** — עיינו לאיזה נתיבים ייכתבו קבצים
5. סגרו את הרשימה. לחצו **Continue** והשלימו את ההתקנה
6. הזינו סיסמת Admin כשתתבקשו
7. נווטו ל-`/Applications/` ופתחו את התוכנה לאישור

!!! note
    אם אשף ההתקנה ביקש Restart — ניתן לדחות לסוף כל התרגילים.

## תרגיל 2 — התקנה מ-DMG ואתגור Gatekeeper ב-Tahoe

> **מה לומדים:** DMG = Volume וירטואלי. גרירה ל-Applications + Eject. ב-Tahoe — Gatekeeper יותר מחמיר.

1. פתחו Safari והורידו קובץ DMG (לדוגמה: VLC מ-[videolan.org](https://www.videolan.org/))
2. לאחר ההורדה, לחצו לחיצה כפולה על הקובץ ב-Downloads
3. חלון ה-DMG ייפתח. גררו את סמל האפליקציה אל קיצור הדרך לתיקיית **Applications**

    > 💡 תראו חלון התקדמות העתקה — ממתינים עד שמסתיים

4. בסרגל הצד ב-Finder (תחת **Locations**) — לחצו על סמל **Eject ⏏** ליד שם ה-DMG
5. עברו ל-`/Applications/` ופתחו את האפליקציה
6. אזהרת Gatekeeper תופיע (זה תקין) → לחצו **Open**

**אתגר Tahoe — אפליקציה ללא חתימה:**

!!! important
    אם ינתן לכם קובץ לא חתום לניסוי:
    - נסו: קליק ימני → Open → **תראו שהאפשרות לא מופיעה יותר ב-Tahoe**
    - הדרך הנכונה: `System Settings → Privacy & Security` → גללו מטה → לחצו **"Open Anyway"**

## תרגיל 3 — Sandboxing ואיפוס Container

> **מה לומדים:** מחיקת אפליקציה מ-Applications לא מוחקת הגדרות. ה-Container הוא מה שצריך.

1. פתחו אפליקציה מובנית (לדוגמה: **Notes** / פתקים)
2. שנו הגדרה כלשהי (צבע, גופן, כל שינוי שתרצו)
3. סגרו לחלוטין: **`Cmd + Q`** (לא רק לחצו X)

**מציאת ה-Container:**

4. פתחו **Finder** ← שורת תפריטים עליונה → **Go**
5. החזיקו מקש `Option (⌥)` — **Library** תופיע ברשימה → לחצו עליה
6. היכנסו לתיקייה **`Containers`**
7. מצאו את תיקיית האפליקציה (לדוגמה: `com.apple.Notes`)

    > 💡 לא מוצאים? Notes לא תמיד יש לה Container. נסו Keynote: `com.apple.iWork.Keynote`

**האיפוס:**

8. קליק ימני על תיקיית ה-Container → **Move to Trash**
9. רוקנו את הפח (**Finder → Empty Trash**)
10. פתחו מחדש את האפליקציה → מסך "ברוכים הבאים" = **האיפוס הצליח** ✅

!!! caution
    **אל תריצו** `killall cfprefsd` בזמן שאפליקציות אחרות פתוחות — הוא ישפיע על הגדרות כל התהליכים הפתוחים.

## תרגיל 4 — Force Quit: שלוש הדרכים

> **מה לומדים:** כדור הים = Not Responding. שלוש דרכים לסגור — מהיר לפי הצורך.

פתחו **Safari** ו-**Calendar** (לוח שנה).

**שיטה 1 — הכי מהיר:**
1. הקישו `Option + Command + Escape`
2. בחלון שנפתח: בחרו ב-**Safari** ← לחצו **Force Quit**
3. אשרו את האזהרה

פתחו מחדש את Safari.

**שיטה 2 — דרך ה-Dock:**
1. קליק ימני על אייקון Safari ב-Dock
2. **בזמן שהתפריט פתוח** — החזיקו `Option`
3. ראו איך "Quit" הופך ל-**"Force Quit"** ← לחצו עליו

פתחו מחדש את Safari.

**שיטה 3 — Activity Monitor (הכי מפורט):**
1. פתחו **Activity Monitor** (ב-Spotlight: `Cmd+Space` → "Activity Monitor")
2. חפשו "Safari" בשורת החיפוש
3. סמנו את התהליך → לחצו **`X`** (כפתור עגול בשורת הכלים למעלה)
4. בחרו **Force Quit** בדיאלוג

    > 💡 שימו לב לעמודת **% CPU** — זה מראה מה "זולל" משאבים

## תרגיל 5 — (הדגמה ודיון) Self Service ו-VPP

> **מה לומדים:** בסביבה ארגונית — MDM מאפשר התקנה ללא Admin וללא Apple ID.

זהו תרגיל הדגמתי — המדריך יציג מהעמדה הראשית.

1. המדריך יפתח **Self Service** (מותקן על ידי ה-MDM אוטומטית)
2. עיינו בקטלוג התוכנות המאושרות לארגון
3. המדריך ילחץ "התקן" → שימו לב: **אין בקשת Admin, אין Apple ID**
4. האפליקציה מותקנת ישירות ל-`/Applications/` ברקע

!!! tip "סימן לבעיית VPP בשטח"
    אם אפליקציה ארגונית מבקשת Apple ID → זהו סימן שה-VPP Token פג תוקפו ב-ABM. צריך לחדש אותו בפורטל.

## תרגיל בונוס — Terminal למתקדמים

!!! caution
    למשתמשים מתקדמים בלבד. לא חובה לתרגיל המרכזי.

```bash
# בדיקת חתימת PKG
pkgutil --check-signature /path/to/installer.pkg

# אימות נוטריזציה של אפליקציה
codesign --test-requirement="=notarized" --verify --verbose /Applications/VLC.app

# ריקון מטמון הגדרות (לאחר איפוס Container)
killall cfprefsd
```
