# שיעור 12: עדכונים ושדרוגים
**מעבדה מעשית (תרגול לתלמיד)**

## מטרת התרגול
תרגול שליטה בעדכוני מערכת (Updates ו-Upgrades) באמצעות ממשק המשתמש (GUI), הבנת מנגנון ה-RSR (Rapid Security Response) דרך הגדרות המערכת, ותרגול תהליך העברת נתונים נכון באמצעות Migration Assistant בסביבה ארגונית.

---

## תרגיל 1: ניהול עדכוני תוכנה בממשק המשתמש הגרפי

**תרחיש:**
עליכם לוודא שהמערכת מעודכנת, להבין היכן מופיעים עדכוני מערכת מינוריים (Updates) לעומת שדרוגים מלאים (Upgrades), ולוודא שעדכוני אבטחה שקטים (Rapid Security Responses / BSI) מוגדרים להתקנה אוטומטית כפי שנדרש בארגון.

### שלב א': איתור עדכונים זמינים

1. פתחו את אפליקציית **System Settings** (הגדרות המערכת).
2. נווטו אל **General** (כללי) ולאחר מכן בחרו ב-**Software Update** (עדכוני תוכנה).
3. המתינו מספר שניות בזמן שהמערכת מחפשת עדכונים בשרתי אפל.
4. שימו לב לחלוקה במסך:
   * **עדכונים מינוריים (Updates):** יופיעו בחלק העליון (למשל מעבר לגרסה 26.1).
   * **שדרוגים גדולים (Upgrades):** עשויים להופיע בחלק התחתון בנפרד (למשל המלצה לשדרוג ל-macOS חדש לגמרי), כדי למנוע התקנה בטעות על ידי המשתמש.

### שלב ב': הגדרת עדכונים אוטומטיים ו-RSR

1. באותו מסך, לחצו על כפתור המידע (סמל ה-**i**) הממוקם לצד השורה של **Automatic Updates**.
2. יוצגו בפניכם מספר מתגים חשובים. ודאו שהמתג הבא דולק:
   **Install Security Responses and system files**
3. **משמעות ארגונית:** הפעלת מתג זה קריטית. היא מאפשרת למערכת ה-macOS לקבל עדכוני אבטחה דחופים, שמגיעים כקפסולות (Cryptex) ומוחלים על המערכת (לרוב ללא צורך באתחול המחשב), וכן לעדכן את רשימות החתימות הזדוניות (XProtect).
4. בסיום הבדיקה, לחצו על **Done**.

### שלב ג': הורדת שדרוג מלא (Upgrade) דרך ה-Terminal

1. לעיתים נרצה להוריד את קובץ ההתקנה המלא (Installer) כדי ליצור כונן USB להתקנה או לפרוס אותו למחשבים אחרים בארגון.
2. פתחו את אפליקציית ה-**Terminal**.
3. הריצו את הפקודה הבאה כדי למשוך את קובץ ההתקנה העדכני ביותר:
   ```bash
   softwareupdate --fetch-full-installer
   ```
   *(במידה ותרצו להוריד גרסה ספציפית תוכלו להוסיף `--full-installer-version 26.0`)*
4. פעולה זו תוריד את קובץ ההתקנה לתיקיית ה-Applications שלכם כקובץ בשם `Install macOS [Name].app`. (תוכלו לעצור כעת את הפעולה בעזרת `Control + C` אם אינכם צריכים את הקובץ).

## תרגיל 2: הדמיית העברת נתונים (Migration Assistant)

**תרחיש:**
המשתמש קיבל Mac חדש ועלינו להעביר את החומר שלו בצורה נכונה מה-Mac הישן או מכונן Time Machine, מבלי לדרוס חשבונות (Local Account) או לייצר כפילויות במערכת החדשה.

### שלב א': הכנות והפעלת הכלי

1. פתחו את **Migration Assistant** מתוך התיקייה `/Applications/Utilities` (או פשוט חפשו ב-Spotlight).
2. הכלי יבקש את סיסמת מנהל המערכת (Admin) ויסגור את כל שאר האפליקציות הפועלות ברקע. אשרו זאת.
3. במסך הראשון, בחרו באפשרות של **From a Mac, Time Machine backup, or startup disk** ולחצו על **Continue**.
4. *בסימולציה זו:* אם מחובר כונן Time Machine למחשב שלכם, בחרו בו. אם לא, פשוט עברו על המסכים והכירו את אפשרויות הבחירה (בלי לבצע העברה בפועל).

### שלב ב': בחירת הנתונים להעברה

1. כשהכלי מזהה את המקור, הוא יחשב את נפח הנתונים ויציג רשימה של פריטים.
2. **Best Practice ארגוני:**
   * פתחו את רשימת החשבונות בעזרת החץ הקטן ליד קטגוריית ה-Users.
   * ודאו שאתם מסמנים ומעבירים **רק** את חשבון המשתמש (Standard / Admin) הרלוונטי. אל תעבירו חשבונות Admin ישנים של צוות ה-IT אם ה-MDM כבר מטפל בהם ב-Mac החדש.
   * בחנו את הקטגוריות: `Applications`, `Other Files & Folders`, `System & Network`.
   * **המלצה ארגונית חזקה:** מומלץ להסיר את ה-V מהקטגוריה `System & Network` כדי למנוע העברת הגדרות רשת ישנות או שאריות מפרופיל התצורה (Configuration Profile) הקודם שעשויים להתנגש. בנוסף, אל תעבירו `Applications` כדי להימנע מהעברת Kexts לא נתמכים (בעיקר במעבר מאינטל ל-Apple Silicon).

### שלב ג': ניהול התנגשות חשבונות (Account Conflict)

1. אם על ה-Mac החדש כבר קיים חשבון בעל שם משתמש זהה לזה שאתם מנסים לייבא, תופיע אזהרה.
2. יוצגו בפניכם אפשרויות פעולה:
   * **Replace:** מחיקת החשבון הקיים על ה-Mac החדש ודריסתו.
   * **Keep both user accounts:** המערכת תשנה את השם של החשבון המיובא כדי לייצר הפרדה.
3. *בסימולציה זו:* בחרו ב-Cancel, וצאו מ-Migration Assistant בצורה מסודרת.

## תרגיל 3: חקירת מנגנון Rapid Security Response (RSR)

**תרחיש:**
בתור מנהלי IT, תרצו לוודא איזה גרסת RSR מותקנת כעת וכיצד ניתן לבטל אותה (Rollback) במקרה של בעיית תאימות עם תוכנות ארגוניות.

1. פתחו את **System Settings** ונווטו אל **General** -> **About**.
2. בדקו את גרסת ה-macOS. אם הותקן עדכון RSR מהיר, תראו אות בסוגריים (למשל `(a)`) ליד מספר הגרסה (כגון `macOS 26.3.1 (a)`).
3. אם ישנו RSR מותקן, לחצו על כפתור המידע (סמל ה-**i**) לצד גרסת ה-macOS.
4. במסך שייפתח תמצאו את כפתור ה-**Remove** שנועד להסיר את עדכון האבטחה המסוים (ביטול טעינת ה-Cryptex באתחול הבא) ולחזור לגרסת הבסיס של המערכת.
