# שיעור 07: גיבוי ושחזור
**מעבדה מעשית (תרגול לתלמיד) (vEXP)**

## מטרת התרגול
הבנה ותרגול של מנגנון הגיבוי המובנה ב-macOS, כולל עבודה עם כונן פיזי חיצוני (Time Machine Backup) ועבודה עם Snapshots מקומיות (Local Snapshots) במערכת קבצים APFS. בתרגיל זה נגדיר כונן חיצוני כיעד גיבוי מוצפן, נבצע שחזור לאחר "אסון" (מחיקת קבצים), ולאחר מכן נתרגל יצירה וניהול של Snapshots מקומיים באמצעות הממשק הגרפי (GUI) ובאמצעות שורת הפקודה (Terminal).

## דרישות קדם

* מחשב מק (Apple Silicon / Intel) עם מערכת macOS מותקנת.
* משתמש בעל הרשאות מנהל (Admin).
* **כונן USB חיצוני (DOK או כונן SSD נייד)** בנפח פנוי של 64GB לפחות.

---

## חלק 1: הגדרת כונן ה-USB ככונן Time Machine

1. חברו את כונן ה-USB החיצוני למק.
2. על מנת לייצר מידע לתרגול, פתחו את ה-**Finder** וצרו תיקייה חדשה על שולחן העבודה (Desktop) בשם `TMLab`.
3. פתחו את האפליקציה **TextEdit**, כתבו טקסט פשוט (למשל "This is highly classified enterprise data"), ושמרו את הקובץ בתוך תיקיית `TMLab` בשם `ImportantData.txt`.
4. פתחו את הגדרות המערכת (**System Settings**) ונווטו ל-**General** -> **Time Machine**.
5. לחצו על **Add Backup Disk...**
6. בחרו את כונן ה-USB החיצוני שלכם מהרשימה ולחצו על **Set Up Disk**.
7. המערכת תשאל האם ברצונכם להצפין את הגיבוי (Encrypt Backup). בחרו להצפין (זהו תרגול אבטחת מידע קריטי בארגונים!) והזינו סיסמת גיבוי שתוכלו לזכור (למשל `1234`).
8. לחצו על **Done**. המערכת כעת מפרמטת את הכונן בתצורת APFS (Case-sensitive) ונועלת אותו ככונן גיבוי.

---

## חלק 2: ביצוע גיבוי ראשוני והדמיית אובדן מידע

1. עדיין במסך ה-Time Machine, המתינו שהגיבוי הראשוני יתחיל.
2. כדי לזרז את התהליך, תוכלו ללחוץ על **Options** ולהוסיף את תיקיית `Applications` ועוד ספריות גדולות לרשימת ההחרגות (Exclude), כך שהוא יגבה רק את המשתמש שלכם.
3. המתינו לסיום הגיבוי (פס ההתקדמות יסתיים והסטטוס ישתנה ל-Oldest backup).
4. **הדמיית אסון:** פתחו את ה-Finder, נווטו לשולחן העבודה, ומחקו את התיקייה `TMLab` (העבירו לפח ורוקנו את פח האשפה). המידע כביכול אבד.

---

## חלק 3: שחזור הנתונים מהכונן החיצוני

1. ודאו שהכונן החיצוני עדיין מחובר.
2. לחצו על סמל ה-Time Machine (שעון עם חץ אחורה) בשורת התפריטים (Menu Bar) העליונה, ובחרו **Browse Time Machine backups**.
3. ממשק ה-Time Machine המוכר ייפתח. ברקע תראו את חלון ה-Finder הנוכחי (ההווה).
4. בצד ימין של המסך, השתמשו בציר הזמן (Timeline) או בחיצים כדי לחזור צעד אחד אחורה בזמן, לנקודה בה בוצע הגיבוי שלנו.
5. אתרו את התיקייה `TMLab` שהופיעה מחדש על שולחן העבודה בנקודת הזמן ההיא.
6. סמנו את התיקייה ולחצו על כפתור ה-**Restore** (שחזר) בתחתית המסך.
7. התיקייה תחזור לשולחן העבודה במערכת החיה. פתחו את הקובץ וודאו שהמידע בפנים זהה.

---

## חלק 4: Snapshots מקומיות (Local Snapshots)

*מה קורה כשהכונן החיצוני לא מחובר?* macOS שומרת גיבויים קטנים מקומיים הנקראים Local Snapshots.

1. נתקו פיזית את כונן ה-USB מהמחשב.
2. פתחו את **Disk Utility** (מתוך `Applications/Utilities/`).
3. בתפריט העליון, לחצו על **View** ובחרו ב-**Show APFS Snapshots**.
4. בחרו את הכונן `Macintosh HD - Data` מצידו השמאלי של החלון.
5. בתחתית המסך תראו רשימה של Snapshots. שימו לב שישנה Snapshot שנוצרה ממש לפני כמה דקות, בעת ביצוע הגיבוי האחרון שלכם.
6. חזרו על "הדמיית האסון" מהחלק הקודם: מחקו שוב את תיקיית `TMLab` ורוקנו את פח האשפה.
7. מבלי לחבר את הכונן החיצוני, היכנסו שוב ל-**Browse Time Machine backups** משורת התפריטים.
8. שימו לב: המערכת מאפשרת את המסע בזמן הודות לתמונת המצב המקומית ב-APFS! בצעו שחזור בדיוק כמו מקודם.

---

## חלק 5: ניקוי הכונן וניהול Snapshots בטרמינל (Terminal)

למרות שראינו כיצד לנהל Snapshots מתוך ה-Disk Utility ב-GUI, מנהלי מערכת (SysAdmins) מרבים להשתמש בשורת הפקודה (Terminal) לביצוע פעולות אלו במהירות וביעילות עם הכלי `tmutil`.

1. פתחו את אפליקציית ה-**Terminal**.
2. **צפייה בסטטוס חי:** הריצו `tmutil status` כדי לראות אם גיבוי רץ ברקע.
3. **הצגת רשימת תמונות המצב:** הריצו `tmutil listlocalsnapshots /`. זה ידפיס את אותה הרשימה שראיתם ב-Disk Utility.
4. **פינוי מקום דחוף (Thinning):** הריצו את הפקודה `tmutil thinlocalsnapshots / 10000000000 4`. זה יורה למערכת למחוק עד כ-10GB של תמונות מצב בדחיפות מרבית כדי לפנות מקום בכונן שלכם.
5. חברו בחזרה את כונן ה-USB החיצוני.
6. פתחו את **Disk Utility**, בחרו את הכונן החיצוני, ולחצו **Erase** (בחרו בפורמט ExFAT או APFS רגיל) כדי לנקות אותו מגיבויי ה-Time Machine ולהכין אותו חזרה לשימוש רגיל.
