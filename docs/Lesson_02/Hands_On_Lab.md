# שיעור 02: ניהול משתמשים ואבטחת נתונים
**מעבדה מעשית (תרגול לתלמיד)**

## מעבדה 1: אבטחה חסרת סיסמה (Passkeys) ואפליקציית Passwords

**מטרת המעבדה:**
התנסות מעשית ביצירת Passkey מול שרת מרוחק, הבנת תהליך האימות בעזרת Secure Enclave, וסקירת התוצאה באפליקציית ניהול הסודות של macOS.

**דרישות קדם:**

* Mac הפועל על macOS 26 (Tahoe) ומעלה.
* קורא טביעות אצבע (Touch ID) מוגדר, או שימוש בסיסמת המחשב.

**שלבי המעבדה:**

### חלק א': יצירת ה-Passkey
1. פתח את דפדפן Safari במחשבך.
2. נווט אל אתר המעבדה: [https://webauthn.io/](https://webauthn.io/).
3. בתיבת ה-**Username**, בחר שם משתמש ייחודי (למשל `OmerAppleClass123`).
4. ודא שסוג ה-Attestation מכוון ל-`None` ולחץ על **Register**.
5. macOS תזהה את בקשת הרישום ותקפיץ חלונית פופ-אפ.
6. אמת את זהותך בעזרת מגע ב-**Touch ID** (או הזנת סיסמת המחשב).
7. לאחר האימות, ה-Secure Enclave מייצר זוג מפתחות קריפטוגרפיים ושומר את המפתח הפרטי בבטחה.

### חלק ב': התחברות נטולת סיסמה
1. כעת באותו דף של [webauthn.io](https://webauthn.io/), גלול חזרה למעלה ולחץ על לחצן ה-**Authenticate**.
2. חלון של Safari יקפוץ וישאל "האם להשתמש ב-Passkey שלך?".
3. גע שוב ב-**Touch ID**.
4. התחברת בהצלחה ללא צורך בהקלדת סיסמה!

### חלק ג': צפייה בסודות באפליקציית Passwords
1. פתח את ה-Spotlight (Command + Space) והקלד **Passwords**. לחץ Enter.
2. אמת את זהותך ב-Touch ID כדי לפתוח.
3. בסרגל הצד (Sidebar), בחר בקטגוריית **Passkeys**.
4. ברשימה, מצא את הרשומה עבור `webauthn.io`.
5. לחץ עליה. שים לב שלא מופיעה סיסמה טקסטואלית, אלא מצוין מפורשות שזהו מפתח גישה חומרתי (Passkey).

### חלק ד': אבטחת פרטיות עם TCC (מעבדת בונוס)
**מטרת המעבדה:** לראות את מנגנון ה-Transparency, Consent, and Control בפעולה.

1. פתח את אפליקציית ה-**Terminal**.
2. הקלד את הפקודה `ls ~/Desktop` ולחץ Enter.
3. סביר להניח שתקפוץ חלונית של מערכת ההפעלה המבקשת לאשר ל-Terminal לגשת לקבצים בתיקיית שולחן העבודה שלך.
4. אם תלחץ על **Don't Allow**, תראה ב-Terminal שגיאת `Operation not permitted` - למרות שמבחינת הרשאות POSIX אתה הבעלים של התיקיה!
5. כדי לתקן זאת, היכנס ל-**System Settings** -> **Privacy & Security** -> **Files and Folders** (או **Full Disk Access**) והענק ל-Terminal את ההרשאה הנדרשת.
