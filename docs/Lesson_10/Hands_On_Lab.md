# שיעור 10: שיתוף וגישה מרחוק
**מעבדה מעשית (תרגול לתלמיד) (Asset D)**

## מטרות התרגול

- הפעלת שיתוף קבצים (File Sharing) וזיהוי שירותים ברשת (Bonjour).
- התחברות לשרתי שיתוף קבצים (SMB) דרך ה-Finder ובשורת הפקודה.
- היכרות עם שיתוף מהיר ב-Apple Silicon באמצעות Mac Sharing Mode והבנת מגבלות כלי התיקון.

---

## תרגיל 1: שיתוף קבצים וגילוי שירותי רשת (Bonjour) דרך Finder

**מה לומדים:** התנסות בסיסית בהפעלת שירות שיתוף קבצים במק, ואיתור שרתים דומים ברשת המקומית בטכנולוגיית Bonjour מתוך ממשק ה-Finder.

1. פתח את אפליקציית **System Settings**.
2. נווט אל **General** ולאחר מכן לחץ על **Sharing**.
3. ברשימת השירותים, הפעל את המתג לצד **File Sharing**.
4. לחץ על כפתור המידע (**i**) שלצד File Sharing. כאן תוכל לראות את התיקיות המשותפות (כמו תיקיית Public) ולהגדיר הרשאות. בסיום, לחץ **Done**.
5. כעת נאתר מחשבים ברשת: פתח חלון **Finder** חדש.
6. תחת **Locations** בסרגל הצד, לחץ על **Network** (או `Shift + Command + K`).
7. חלון הרשת יציג את כל השרתים המכריזים על עצמם באמצעות Bonjour. 
8. לחיצה כפולה על אחד מהמחשבים תאפשר חיבור מהיר (לחץ על **Connect As** להזנת פרטי הזדהות).

!!! note "הערת אבחון"
    אם אינך רואה מחשבים אחרים בחלון ה-Network, ייתכן שרשת ה-Wi-Fi חוסמת תעבורת mDNS (מצב Client Isolation שקיים בראוטרים במקומות ציבוריים).

---

## תרגיל 2: חיבור ישיר לשרת קבצים (SMB)

**מה לומדים:** התחברות ישירה ומבוססת כתובת (בפרוטוקול SMB) לשרת קבצים, והבנת הדרך לשמירת נתיבים במועדפים.

1. פתח חלון **Finder**.
2. בשורת התפריטים העליונה, בחר ב-**Go** > **Connect to Server** (או `Command + K`).
3. בשורת הכתובת, הקלד את נתיב השרת בפרוטוקול SMB, לדוגמה:
   `smb://192.168.1.10/SharedFiles`
   *(המדריך יספק את הכתובת המדויקת למעבדה).*

4. לחץ על כפתור ה-`+` לשמירת הכתובת במועדפים, ואז **Connect**.
5. הזדהה כ-**Registered User**, הזן סיסמה, וסמן **Remember this password in my keychain** לנוחות עתידית. 
6. לחץ על **Connect**. כונן הרשת יופיע תחת Locations ב-Finder או על שולחן העבודה.

---

## תרגיל 3: שיתוף מהיר (Mac Sharing Mode)

**מה לומדים:** שימוש בכלי ה-Share Disk מתוך ה-Recovery Mode במחשבי Apple Silicon כדי לחלץ נתונים מ"מק תקול" (כשרת SMB), תוך הבנת המגבלות של כלי ה-Disk Utility בחיבור מסוג זה.

!!! warning "שימו לב"
    מכיוון שהמעבדה נעשית בסביבת ייצור, יש להימנע מלכבות מחשבים חיים ולבצע תרגיל זה בפועל אלא אם המדריך אישר זאת.

1. במחשב אותו נרצה לשתף ("מחשב היעד"), יש להיכנס ל-**Recovery Mode** (לחיצה ארוכה על כפתור ההפעלה במצב כבוי עד להופעת Options).
2. לאחר אימות משתמש, בשורת התפריטים לחץ על **Utilities** ובחר **Share Disk**.
3. בחר את הווליום הרצוי (כגון `Macintosh HD`) ולחץ על **Start Sharing**.
4. חבר את כבל הנתונים (Thunderbolt) בין שני המחשבים.
5. ב"מחשב המארח", פתח **Finder** ועבור ל-**Network**. "מחשב היעד" יופיע שם כשרת קבצים (SMB).
6. לחץ עליו, בחר **Connect As**, והזן את סיסמת ה-Admin של "מחשב היעד" לפענוח ההצפנה.
7. **דגש IT קריטי:** אם תפתחו עכשיו את Disk Utility במחשב המארח, **לא תראו את הדיסק הפיזי של מחשב היעד**. מצב זה הוא למעשה שרת SMB. אי אפשר להריץ First Aid מהמחשב המארח על המחשב המשותף. 
8. בסיום ההעתקה, בצעו Eject (ניתוק הכונן), ולאחר מכן במחשב היעד לחצו על **Stop Sharing** ובצעו Restart (הפעלה מחדש).

---

## תרגיל בונוס לאנשי IT: שורת הפקודה (Terminal)

**מה לומדים:** ביצוע פעולות שיתוף מורכבות יותר מתוך שורת הפקודה, כמו סריקת הרשת לשירותי mDNS חבויים, ועיגון כונני SMB ישירות מהטרמינל.

1. **איתור ופרסום שירותים בעזרת `dns-sd` ו-`sharing`**:
   כדי להציג את רשימת שירותי השיתוף (Share Points) שמוגדרים כרגע במערכת, פתח את הטרמינל והקש:
   ```bash
   sharing -l
   ```
   כדי לחפש שרתי SMB אחרים שמפרסמים את עצמם ברשת המקומית, השתמשו בכלי ה-mDNS:
   ```bash
   dns-sd -B _smb._tcp
   ```
   *(הפקודה רצה ברצף. לחצו על `Control + C` לעצירה).*

2. **חיבור לשרת משורת הפקודה (`mount_smbfs`)**:
   אפשר לעגן כונני רשת ישירות דרך הטרמינל במקום להשתמש בחלונות הגרפיים.
   יצירת תיקיית עוגן:
   ```bash
   mkdir ~/Desktop/MyServer
   ```
   התחברות (יופיע במסך בקשה להזנת סיסמה):
   ```bash
   mount_smbfs //username@server_address/share_name ~/Desktop/MyServer
   ```
   לניתוק הכונן בסיום השימוש: 
   ```bash
   umount ~/Desktop/MyServer
   ```
